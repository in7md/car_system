# 🚗 نظام إدارة معرض السيارات (Car Dealership System)

نظام متكامل لإدارة معارض السيارات مصمم بالكامل لتلبية احتياجات السوق العربي. يغطي النظام جميع العمليات الأساسية من الشراء والمصروفات، إلى المبيعات، وإدارة الصلاحيات والرقابة.

## ✨ الميزات الأساسية (Core Features)
1. **إدارة أسطول السيارات (Vehicle Management):** تتبع معلومات السيارة (رقم الهيكل، لوحة التسجيل، الحالة، الخ).
2. **المشتريات والبائعين (Purchases & Sellers):** تسجيل فواتير الشراء والدفعات ومتابعة حسابات البائعين.
3. **المصروفات والإصلاحات (Expenses & Repairs):** ربط المصاريف الإضافية (صيانة، فحص، تأمين) بتكلفة السيارة لحساب صافي التكلفة الحقيقي.
4. **المبيعات والعملاء (Sales & Customers):** إصدار فواتير البيع وحساب الأرباح (P&L) بناءً على سعر البيع مطروحاً منه تكلفة الشراء والمصروفات.
5. **لوحة التحكم والتقارير (Dashboard & Reports):** إحصائيات حية لرأس المال النشط والأرباح، وتصدير التقارير إلى Excel/CSV و PDF بتنسيق داعم للأحرف العربية.
6. **QR Codes:** توليد باركود لكل سيارة للوصول السريع لملفها.
7. **إدارة الصلاحيات (RBAC):** التحكم بالأدوار (مالك، مدير، محاسب، موظف) لضمان أمان البيانات.
8. **سجل الرقابة (Audit Logs):** سجل شامل لتتبع جميع العمليات التي يقوم بها المستخدمون.

---

## 🛠 المتطلبات التقنية (Prerequisites)
- **Node.js**: إصدار 18 أو أحدث.
- **PostgreSQL**: قاعدة البيانات الأساسية.
- حساب NextAuth جاهز للإعداد (عبر JWT و Credentials).

## 🚀 دليل التشغيل المحلي (Local Setup Guide)

**الخطوة 1:** استنساخ المشروع وتثبيت الحزم
```bash
git clone <repository_url>
cd car_sestem
npm install
```

**الخطوة 2:** إعداد متغيرات البيئة
1. انسخ ملف `.env.example` إلى `.env`.
2. قم بتعديل `DATABASE_URL` برابط قاعدة بيانات PostgreSQL الخاصة بك.
3. قم بتوليد `NEXTAUTH_SECRET` باستخدام الأمر `openssl rand -base64 32` وضع القيمة الناتجة.

**الخطوة 3:** تجهيز قاعدة البيانات
```bash
# بناء الجداول والمخطط (Schema)
npm run db:migrate

# تشغيل الـ Seed لإنشاء الأدوار، الفئات، وحساب المالك الافتراضي
npm run db:seed
```

**الخطوة 4:** تشغيل الخادم
```bash
npm run dev
```

## 🌍 دليل النشر للإنتاج (Deployment Guide - Vercel / VPS)

### الخيار 1: Vercel (موصى به للواجهات)
1. اربط مستودع GitHub بحسابك في Vercel.
2. أضف متغيرات البيئة `.env` في صفحة إعدادات المشروع (Settings > Environment Variables).
3. ضع أمر البناء: `npm run build`
4. سيتولى Vercel البناء والنشر تلقائياً. تأكد من استضافة قاعدة البيانات (PostgreSQL) في خدمة منفصلة (مثل Supabase أو AWS RDS).

### الخيار 2: VPS (Docker / PM2)
1. ثبت Node.js و PM2.
2. شغل الأوامر:
   ```bash
   npm install
   npm run build
   npx prisma migrate deploy
   ```
3. ابدأ الخادم بـ PM2:
   ```bash
   pm2 start npm --name "car_system" -- start
   ```
